# おこづかいちょう つかいかたガイド

## アプリのURLを確認する

ターミナルで以下のコマンドを実行すると、アプリのURLが表示されます。

```bash
# フロントエンドURL（ブラウザでアクセスするURL）
aws cloudformation describe-stacks --stack-name FamilyBankFrontend --profile clshinji \
  --query 'Stacks[0].Outputs[?OutputKey==`DistributionUrl`].OutputValue' --output text
```

表示されたURL（例: `https://dm4ne9bmy3let.cloudfront.net`）の末尾に `/parent` をつけると親ダッシュボード、`/kids/{childId}` をつけると子ども用ページにアクセスできます。

子ども用ページのURLは、親ダッシュボード（`/parent`）の各子どもカードの下にある「こども用ページ →」リンクからも確認できます。

## はじめかた

### 1. こどもを とうろくする

1. `/parent` にアクセスします
2. 「+ こどもを ついか」ボタンをタップ
3. なまえを入力して、アバター（動物アイコン）を選びます
4. 「ついか」ボタンをタップすると登録完了です

複数の子どもを登録できます。

### 2. おこづかいを あげる

1. `/parent` の子ども一覧から、おこづかいをあげたい子をタップ
2. 「あげる」モードが選ばれていることを確認
3. テンキーで金額を入力（例: 500）
4. 「だれが？」でおとうさん、おかあさんなどを選択（または直接入力）
5. 必要に応じてメモを入力（例: おてつだい）
6. 緑色の「あげる」ボタンをタップ

### 3. おこづかいを つかう（回収する）

1. 子どもの操作ページで「つかう」モードに切り替え
2. 使った金額を入力
3. だれが使ったかを入力
4. メモに何に使ったかを記入（例: おかし）
5. オレンジ色の「つかう」ボタンをタップ

残高がマイナスになっても操作できます（親の立て替え）。

### 4. こどもが 残高をかくにんする

子ども専用ページ `/kids/{childId}` にアクセスすると:

- 大きな数字で今の残高が表示されます
- 「りれきを みる」をタップすると入出金の履歴が見られます

QRコードを印刷してタブレットの近くに貼っておくと、子どもが自分でアクセスしやすくなります。

## ページの使い分け

| だれが | どのページ | やること |
|---|---|---|
| おとうさん・おかあさん | `/parent` | 子どもの登録・一覧確認 |
| おとうさん・おかあさん | `/parent/{childId}` | おこづかいをあげる・つかう |
| こども | `/kids/{childId}` | のこりを確認する |
| こども | `/kids/{childId}/history` | りれきを確認する |

## こんなときは

### 金額をまちがえた

現時点では取引の取り消し機能はありません。間違えた場合は、逆の操作（あげすぎた場合は「つかう」、引きすぎた場合は「あげる」）で調整してください。メモに「訂正」と書いておくとわかりやすいです。

### 子どもの名前を変えたい

API経由で変更できます（`PUT /children/{childId}`）。管理画面での変更機能は今後追加予定です。

### QRコードを作りたい

子ども用ページのURL（`https://<ドメイン>/kids/{childId}`）をQRコード生成サービスで変換してください。印刷して冷蔵庫やタブレットスタンドに貼ると便利です。
